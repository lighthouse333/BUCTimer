# BUCTimer v2.0.0

`versionCode: 11`

这是应用定位与交互结构的一次大版本升级。应用正式更名为 **BUCTimer**，由通用课表工具转型为面向北京化工大学学生的校园学习工具。

## 新增

- 五栏底部导航：待办、课表、番茄钟、学业和设置。
- 支持多级子项、完成标记、编辑、折叠动画和侧滑删除的待办功能。
- 支持自定义专注/休息时长、暂停、恢复、重置和目标管理的番茄钟。
- 课表新增仅显示当天课程的简洁视图，并记住上次使用的视图模式。
- “学业”页面预留考试查询、成绩查询和绩点查询入口。

## 北化专属调整

- 课表导入入口调整为北化标准课表 PDF 和北化教务系统在线导入。
- 北化课表导入后自动应用学校作息时间。
- 桌面名称和小组件搜索名称统一更新为 BUCTimer。

## 尚在开发

- 考试查询
- 成绩查询
- 绩点查询

本次升级保留原应用包名和签名，已安装旧版本的用户可以直接覆盖更新，本地课表数据会继续保留。
