# BUCTimer v2.1.0

`versionCode: 12`

本轮围绕北京化工大学教务系统，上线了学业查询，并大幅完善在线导入体验。

## 学业页：成绩、考试与绩点

- 「学业」页不再是占位页，登录后即可查询成绩、考试安排与绩点。
- 显示每门课程的成绩（兼容百分制与等级制）、学分与绩点；不计绩点的课程单独标注。
- 顶部展示平均学分绩点（GPA），直接使用教务系统官方值。
- 考试安排按时间排序展示，包含时间、教室、座位号与监考教师。
- 支持选择学年与学期；学期数据自动缓存，切走再进不重复请求，点「刷新」重新拉取。

## 在线导入：自动登录

- 课表在线导入不再需要手动走登录页：在对话框输入学号与统一认证密码后，后台自动完成登录并直接拉取课表。
- 登录失败会明确提示「账号或密码错误」，不再出现空白登录页。
- 修复了登录页白屏、明文跳转被拦截、会话 Cookie 取不到、换账号残留旧会话等一系列问题。
- 导入时校验登录账号与所填学号一致，避免拉错数据。

## 账号密码管理

- 设置页新增「北京化工大学统一身份认证」：可手动添加、修改、删除默认账号密码。
- 账号密码使用系统密钥（Android Keystore）加密保存在本机，不会明文落盘。
- 登录时输入相同学号，会弹窗询问是否自动填充密码；密码框支持明文切换。
