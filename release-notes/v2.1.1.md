# BUCTimer v2.1.1

`versionCode: 13`

本轮修复学业页的查询交互问题，并让成绩与考试结果在本地保存，后续打开无需重复请求教务系统。

## Bug 修复

- 教务系统返回错误（HTTP 错误、会话异常等）后，错误面板现在同时提供「重试」与「重新登录」两个入口，不再出现无法重新登录的困境。
- 修复修改「学年起始年」后直接点「刷新」不生效的问题：刷新现在会先提交屏幕上已编辑的学年与选中的学期，再强制联网拉取最新数据。

## 功能优化

- 学业页新增「查询」按键：修改学年起始年后一键查询对应学期，不再只依赖键盘「完成」键；输入无效年份时会恢复为当前已查询年份。
- 秋冬 / 春夏 / 暑假三个学期的成绩与考试结果在查询成功后保存到本机；下次进入学业页或重启 App 后直接展示上次结果，不再自动重复请求教务系统。
- 学年起始年与选中学期会记住上次关闭 App 时的状态，重新打开时自动恢复。
- 学生卡片底部展示数据更新时间，来自本地缓存的数据会标注「本地缓存」，需要最新数据时点「刷新」。
- 退出登录时清空该账号的本地学业缓存。
